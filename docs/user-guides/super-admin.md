# G-Link guide for the Super Admin

The first Super Admin is created on the server: `cd server && npm run create-super-admin -- you@rub.edu.bt`
(it asks for the password; nothing is stored in Git). Then sign in and complete your profile.

- **Accounts** — search by name or email, filter by role. **Edit** to change the role (Guest, Incharge, Admin,
  Super Admin) or switch an account off (*Inactive* accounts cannot sign in, and are signed out at once).
- New staff first sign up as normal guests; then you change their role here.
- You cannot change your own account, and there must always be at least one active Super Admin.
- You also have every admin page (see the admin guide).
